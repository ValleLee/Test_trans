# 2026-09-29 Judge JSON 协议修复

## 发现

`rev_001` 的产物契约通过，但语义 Judge 连续两次返回了推理文本，没有可解析的 JSON 对象。流水线正确停止在 `rejected_semantic`，未误把不确定结果当作通过。

## 原因

Judge 请求只依赖提示词约束 JSON。当前 reasoning 模型可能把整个 completion 用于分析，OpenAI-compatible 请求没有启用 JSON mode，因此解析器无法得到 verdict。

## 修复

- OpenAI-compatible 客户端支持可选 `response_format` 请求字段。
- Anthropic-compatible 客户端把该选项转为 JSON-only 系统提示，保持接口一致。
- Judge 优先请求 `{"type":"json_object"}`；旧网关拒绝该字段时回退到普通请求，保持兼容。
- 保留现有严格解析和一次重试逻辑，协议失败仍会阻断流水线。
